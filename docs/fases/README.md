## Convenciones

- **Planeación:** objetivo, alcance, actividades, criterios de aceptación, riesgos.
- **Cierre:** resultado, evidencia, deuda consciente, handoff y aprobación.
- **Aprobación:** no se inicia una fase sin confirmación del usuario.
